ShakeSearch for Windows 10/11 x64

Download and open ShakeSearch.exe. Python and dependencies are included in one file.
They are extracted temporarily at startup, so launch can take longer.
No _internal directory needs to sit beside the EXE.
Microsoft Edge WebView2 Runtime must be installed on Windows.
No Groq account or API key is needed.

Click Select area in the control window or shake the mouse to select an area of the screen.
Only Lens searches send your selected image and questions to Google. Complete any Google
consent or verification requests in the Lens window.
Logs: %TEMP%\shakesearch.log

This is an unsigned experimental build. Windows may show a publisher warning.

The terminal stays visible while ShakeSearch runs. The control window shows
whether the app is active. On first launch, save your language, mouse-shake
sensitivity, and animation preferences. Reopen Settings to change them later.
Use Select area for manual capture. Alt+F7 enables or disables shake detection.
Use the main window's Shake attivi / Shakes enabled toggle to switch modes directly,
without a keyboard shortcut. The app remains usable even if Alt+F7 is unavailable.
Disabling shakes enables Gaming mode to avoid interference while gaming with high DPI.
Select area remains available. Alt+F7 re-enables shakes. The preference is saved.
Notifications confirm the state at startup and whenever it changes; disabled shakes
are labelled Gaming mode. Windows notification settings may silence these messages.
Close the control window or press Quit to stop ShakeSearch.

Copying text from images is coming soon and is not available in this release.
